# Kryoss CRUD

Simple items CRUD app with React (client) and Express + MySQL (server).

- client/: React + Vite frontend
- server/: Express API with MySQL

## Local setup
- Client: `cd client/client && npm install && npm run dev`
- Server: `cd server && npm install && npm run dev`

Make sure MySQL is running and update `server/.env` with credentials.
